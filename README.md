# Box Log: setup (one time, about 10 minutes)

1. Create a free account at github.com and sign in.
2. Click **New repository**. Name it `boxlog`, keep it Public, and click **Create repository**.
3. Click **uploading an existing file**, drag in every file from this folder (index.html, sw.js, manifest.webmanifest, jszip.min.js, both icon-*.png files), and click **Commit changes**.
4. Go to **Settings > Pages**. Under Branch, choose **main** and **/ (root)**, then **Save**.
5. After a minute, your app is at `https://YOUR-USERNAME.github.io/boxlog/`.
6. Open that link on each phone and add it to the home screen (iPhone: Safari, Share, Add to Home Screen. Android: Chrome menu, Install app).

Notes
- The repository is public, but it only holds the app. Box data stays on phones and in the backup files you share.
- To update the app later, upload the changed files again. Users get the update next time they open it online.
- Tap **Share** on the Backup tab regularly. A phone can clear browser data if it runs low on storage.
