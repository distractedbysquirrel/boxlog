# Box Log (version 0.8.4)
Files: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.

To publish or update on GitHub Pages:
1. Open your repository on github.com. Delete the old app files if their names differ from the five above.
2. Click Add file > Upload files, drag in all five files (same names replace the old ones), then Commit changes.
3. The first time only: go to Settings > Pages, set Source to "Deploy from a branch", choose the main branch and the / (root) folder, and Save.
4. Wait 1-2 minutes. Open your Pages address and reload. If the old version still shows, close the app fully and reopen it, or remove it from the home screen and add it again.

Install: iPhone: Share > Add to Home Screen. Android: menu > Install app.

Updates: the app opens from the copy saved on the phone, so a new version shows up the second time it is opened after you publish it.

Backups: on the Backup tab, Share makes one zip file (recipients.csv, categories.csv, items.csv, picks.csv and a photos folder). Import loads it back, and asks whether to replace or merge. Older .json backups can still be imported.
