To publish or update on GitHub Pages:
1. Open your repository on github.com. Delete the old app files if their names differ from the five above.
2. Click Add file > Upload files, drag in all five files (same names replace the old ones), then Commit changes.
3. Wait 1-2 minutes. Open your Pages address and reload. If the old version still shows, close the app fully and reopen it, or remove it from the home screen and add it again.
Install: iPhone: Share > Add to Home Screen. Android: menu > Install app.
